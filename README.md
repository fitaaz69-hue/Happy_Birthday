# Happy Birthday, Rayan ❤️

A responsive birthday website built with HTML, CSS, and vanilla JavaScript. This copy includes the six photos and birthday music from the supplied archive.

## Open in VS Code

1. Open this `rayan-birthday` folder in VS Code using **File → Open Folder…**.
2. Install the **Live Server** extension if needed.
3. Open `index.html` and click **Go Live** in the VS Code status bar. The local site opens in your browser.

## Included media

- The gallery photos are `images/photo1.jpg` through `images/photo6.jpg`. Replace any of them with another JPEG, keeping the same filename, to update the gallery.
- The optional soundtrack is `audio/romantic-music.mp3`. Replace it with your preferred audio file under the same name. Visitors must press the music button before playback starts.

## Publish and share

For GitHub Pages, upload the complete contents of this folder to a repository with `index.html` at the top level. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select the branch containing the files and the root folder, then save. Once Pages publishes the site, copy its website address from the Pages settings and share it. A static hosting service can also publish this folder; keep the `images` and `audio` folders alongside `index.html`.

The countdown uses each visitor's local date and time. The page honors reduced-motion preferences and does not autoplay sound.
